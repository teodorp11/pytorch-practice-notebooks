# Pytorch Practice Notebooks

This repository is a collection of interactive Python notebooks written in PyTorch. It serves as a personal log of my code, exercises, and experiments.

## About

All original foundational notebooks are part of the online course **PyTorch for Deep Learning Bootcamp** by Daniel Bourke and are freely available at [learnpytorch.io](https://www.learnpytorch.io/).

While the structure and topics are based on the original course materials, the notebooks in this repository contain my own code snippets, practice implementations, and personal notes written while working through the curriculum.

## Usage

To explore or run the code locally, clone the repository:

```bash
git clone https://github.com/teodorp11/pytorch-practice-notebooks.git
cd pytorch-practice-notebooks
```

**Note on Execution:**
These notebooks are best viewed and executed in **Google Colab** or a local Jupyter environment to take advantage of GPU acceleration. If running locally, ensure you have a Python environment set up with `torch`, `torchvision`, and `jupyter`.
